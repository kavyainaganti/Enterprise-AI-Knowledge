# Password Standard (Version 2.0, 2022) - Superseded

> **LABELLED CONTRADICTION EXAMPLE - NOT AUTHORITATIVE.** This standard was superseded on 1 April 2025 by IT-GDL-002 Identity, Password and Access Management Guideline. It reflects older practice that the company no longer follows.

## Requirements

| Control | Requirement (2022) |
|---|---|
| Minimum password length | **8 characters**, with upper case, lower case, a number and a symbol |
| Password change | **Every 90 days** |
| Account lockout | After **3 failed attempts** |
| Multi-factor authentication | Required for VPN only |
| One-time codes | **SMS codes accepted** as the standard second factor |

## Note for testers

A correct system answers "How long must my password be?" with 14 characters from IT-GDL-002, states that there is no forced periodic change, and flags this document as superseded if it is retrieved.
